## Context
A business model: who it serves, what it brings them, how it reaches them and earns money, and what it relies on and costs.

- Each business model is named after the model it describes (`Docbook today`); a scenario is another business model.
- Write every known property on every business model, with `undefined` when the context does not say.
- When an item concerns only one segment, start it with that segment (`Practices: monthly subscription`).

## Description
- Kind: text
- Single: yes
- Meaning: What the model is, in one sentence.

## Customer segments
- Kind: text
- Meaning: The groups of people or organizations the model serves.

## Value propositions
- Kind: text
- Meaning: What the model brings to each segment: the problems it solves, the needs it meets.

## Channels
- Kind: text
- Meaning: How the model reaches its segments and delivers its value.

## Customer relationships
- Kind: text
- Meaning: The kind of relationship with each segment (self-service, personal help…).

## Revenue streams
- Kind: text
- Meaning: What each segment pays for, and how.

## Key resources
- Kind: text
- Meaning: What the model depends on most (people, technology, data…).

## Key activities
- Kind: text
- Meaning: What must be done well for the model to work.

## Key partners
- Kind: text
- Meaning: The partners and suppliers the model relies on, and what they bring.

## Cost structure
- Kind: text
- Meaning: The main costs of running the model.
